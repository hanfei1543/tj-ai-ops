# GOLD HARVEST 成本代号 编码规范

> 补充 Z=千（2026-11-06 用户确认）；用于 Item Master 的 Color Code（界面标签「Colour」）编解码。

## 数字字母映射
G=1, O=2, L=3, D=4, H=5, A=6, R=7, V=8, E=9

## 位值标记
Z=RM1000（千）, T=RM100（百）, S=RM10（十）, Y=RM1（个）, X=RM0.10（角）

## 编码规则
- 价格按 [数字字母][位值标记] 成对写出，从高位到低位；数值字母紧跟位值标记 = 相乘，多段相加。
- 没有出现的位 = 零（中间零位省略）。
- 个位为零时，末尾写裸 Y（如 LTDSY=340、GZGSY=1010）。

## 已确认示例
- AX = 6×0.10 = RM0.60
- EY = 9×1 = RM9.00
- OSHY = 2×10 + 5×1 = RM25.00
- LTDSY = 3×100 + 4×10 = RM340.00
- GZGSY = 1×1000 + 1×10 = RM1010.00
